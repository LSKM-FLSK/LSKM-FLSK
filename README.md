# LSK M – Social Media Analytics

## About

**LSK M – Social Media Analytics** is an internal social media analytics application operated by **LSK Employee**.

The application is designed for in-house data collection and analysis of social media performance across supported platforms.

It is used to collect and organise analytics such as:

* Post views
* Likes
* Comments
* Shares
* Engagement
* Watch-time data
* Post performance
* Account performance

The information collected is used to help analyse social media content performance and improve internal reporting and decision-making.
